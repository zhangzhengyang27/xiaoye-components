# 前台基础组件库第一期实现计划

## 0. 前缀规范

> 前缀 `xyu-`（Xyu*）用于 xiaoye-ui 前台专属组件，与 xiaoye-components 的 `Xy*` 前缀完全区隔，避免同项目同时安装两包时的命名冲突。

| 包 | 组件前缀 | 示例 |
|----|---------|------|
| `@xiaoye/components` | `Xy-` / `xy-` | `XyButton` / `xy-button` |
| `@xiaoye/ui`（前台） | `Xyu-` / `xyu-` | `XyuButton` / `xyu-button` |

**现有前台组件迁移**（本次同步执行）：

| 旧名称 | 新名称 | 涉及文件 |
|--------|--------|---------|
| `XyProductCard` | `XyuProductCard` | 组件源码、index.ts、component-manifest.json、示例文档 |
| `XyMarketingModal` | `XyuMarketingModal` | 同上 |
| `XyImageGallery` | `XyuImageGallery` | 同上 |
| `XySkuSelector` | `XyuSkuSelector` | 同上 |
| `XyAddressPicker` | `XyuAddressPicker` | 同上 |

> 注：文档站中的示例 `.vue` 文件和 `.md` 文档均未发现旧前缀引用，说明示例可能还未实际编写，迁移成本较低。

## 1. 设计系统定义

**风格**：极简精准（Clean Minimal）—— 大量留白、严谨对齐、低饱和色彩、无彩色为主。继承现有前台主色调 `#5b76fe`，在圆角、阴影、边框等细节上做极简化处理。

**前台设计令牌**（在 `packages/theme/src/front/front-tokens.css` 中扩展）：

```css
[data-theme="front"] {
  /* 圆角 */
  --xy-radius-sm: 4px;
  --xy-radius-md: 6px;
  --xy-radius-lg: 8px;
  --xy-radius-xl: 12px;
  --xy-radius-pill: 9999px;

  /* 阴影：极轻、无彩色 */
  --xy-shadow-sm: 0 1px 3px rgba(0, 0, 0, 0.06);
  --xy-shadow-md: 0 4px 12px rgba(0, 0, 0, 0.08);
  --xy-shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.1);

  /* 主色：低饱和蓝灰 */
  --xy-primary-color: #5b76fe;
  --xy-primary-light: rgba(91, 118, 254, 0.08);
  --xy-primary-hover: #4a62e8;

  /* 中性色 */
  --xy-text-primary: #1a1a2e;
  --xy-text-secondary: #6b7280;
  --xy-text-tertiary: #9ca3af;
  --xy-bg-white: #ffffff;
  --xy-bg-gray: #f8f9fa;
  --xy-border: #e5e7eb;
  --xy-border-hover: #d1d5db;

  /* 成功/警告/错误 */
  --xy-success: #10b981;
  --xy-warning: #f59e0b;
  --xy-error: #ef4444;

  /* Focus ring */
  --xy-focus-ring-color: rgba(91, 118, 254, 0.3);
}
```

**前台基础 reset**（`packages/theme/src/front/front-base.css` 中扩展）：

- `.xy-btn` / `.xy-input` / `.xy-select` 等基础样式覆盖，贴合极简风格
- 极细边框（1px），hover 时加深，无多余装饰
- 过渡时间统一 `0.15s ease`

## 3. 目录结构规范

```
packages/xiaoye-ui/src/front-components/
  button/
    index.ts          # 导出 + 安装
    button.vue        # 组件
    button.css        # 前台样式
  input/
    index.ts
    input.vue
    input.css
  select/
    index.ts
    select.vue
    select.css
  ... 依此类推
```

每个组件目录结构：
- `index.ts` — 导出组件 + 类型 + install 函数
- `*.vue` — 组件模板
- `*.css` — 前台专属样式（覆盖默认主题）

---

## 4. 入口文件同步

每实现一个组件，需同步更新：

1. `packages/xiaoye-ui/src/front-components/index.ts` — 添加 export
2. `packages/xiaoye-ui/index.ts` — 聚合导出 + install 注册
3. `packages/xiaoye-ui/style.css` — 导入对应 CSS
4. `packages/theme/src/front/front-tokens.css` — 设计令牌（如需新增）
5. `packages/theme/src/front/front-base.css` — 基础 reset 覆盖

## 6. 技术要点

- 前台组件 **不依赖** `@xiaoye/components`，完全独立
- 组件内可通过 `@xiaoye/primitives` 复用 `useNamespace`、`useConfig` 等组合式逻辑
- 样式使用 CSS 原生变量，与 `front-tokens.css` 保持一致
- TypeScript 类型定义参考 `packages/components/` 中对应组件的 Props 接口
- 前台专属组件命名：`XyuButton`、`XyuInput`（与后台 `XyButton` 完全区隔）
- 前台组件内部**不再依赖** `@xiaoye/components` 的 Icon/Image/Badge 等，需使用前台自己实现的版本
- 现有 headless 组件（`XyDialogRoot`、`XyTabGroup` 等）保持原样，前台 UI 组件与其**并行共存**，用户按需选择
