# 前台基础组件库 Phase 2 计划

## Phase 2 目标

1. 补全表单类组件缺口

## 4. 主题系统增强

### 4.1 暗色模式

在 `packages/theme/src/front/front-tokens.css` 中新增暗色模式变量块：

```css
[data-theme="front"][data-theme-mode="dark"],
[data-theme="dark"] {
  --xyu-bg: #1a1a2e;
  --xyu-bg-secondary: #16162a;
  --xyu-bg-tertiary: #22223b;
  --xyu-text-primary: #f0f0f5;
  --xyu-text-secondary: #a0a0b8;
  --xyu-text-tertiary: #6b6b8a;
  --xyu-border: #2e2e4a;
  --xyu-border-hover: #3d3d60;
  --xyu-shadow-sm: 0 1px 3px rgba(0, 0, 0, 0.4);
  --xyu-shadow-md: 0 4px 12px rgba(0, 0, 0, 0.5);
  --xyu-shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.6);
}
```

### 4.2 组件级主题覆盖

建立 `packages/theme/src/front/themes/` 目录，按组件拆分主题变量文件：

```
themes/
  button-tokens.css   # xyu-button 专属变量（--xyu-btn-height-* 等）
  input-tokens.css    # xyu-input 专属变量
  dialog-tokens.css   # xyu-dialog 专属变量
  ...
```

每个 token 文件通过 CSS 变量覆盖默认值，支持两种用法：

```css
/* 全局覆盖 */
:root {
  --xyu-button-height: 40px;
  --xyu-button-font-size: 15px;
}

/* 组件级覆盖 */
.xyu-button {
  --button-height: 40px; /* 组件内部引用 */
}
```

### 4.3 主题切换工具函数

在 `packages/theme/src/front/` 新增 `useTheme.ts` 组合式函数：

```typescript
// useTheme.ts
export function useTheme() {
  const setThemeMode = (mode: 'light' | 'dark') => {
    document.documentElement.setAttribute('data-theme-mode', mode);
  };
  const toggleDark = () => {
    const current = document.documentElement.getAttribute('data-theme-mode');
    setThemeMode(current === 'dark' ? 'light' : 'dark');
  };
  return { setThemeMode, toggleDark };
}
```

## 6. 目录结构规范

Phase 2 新增组件遵循与 Phase 1 相同的结构：

```
packages/xiaoye-ui/src/front-components/<name>/
  index.ts          # 导出 + withInstall
  <name>.ts         # 类型定义
  <name>.vue        # 组件实现
  <name>.css        # 前台专属样式
```

样式统一在 `packages/xiaoye-ui/style.css` 中通过 `@import` 导入。
